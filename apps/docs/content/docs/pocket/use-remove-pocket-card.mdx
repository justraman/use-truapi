---
title: useRemovePocketCard
description: Give one of the product's Pocket cards up
---

`useRemovePocketCard` removes a card from the host's Pocket tab:
`remove(cardId)` resolves once it is gone. Removing a card that is not
present succeeds; a `privileged` card (one the host placed itself) is refused
and the call rejects. The card's draw handler stays registered, so the product
draws it again if the host ever restores it. Host-only: standalone `remove`
rejects with `HostUnavailableError`.

## Usage

<Tabs groupId="framework" persist items={['React', 'Vue']}>
<Tab value="React">

```tsx
import { usePocketCards, useRemovePocketCard } from "@use-truapi/react";

function DismissButtons() {
  const { data: cards } = usePocketCards();
  const { remove, isPending } = useRemovePocketCard();
  return (
    <>
      {cards?.filter((c) => !c.privileged).map((card) => (
        <button key={card.cardId} type="button" disabled={isPending} onClick={() => remove(card.cardId)}>
          Dismiss {card.cardId}
        </button>
      ))}
    </>
  );
}
```

</Tab>
<Tab value="Vue">

```vue
<script setup lang="ts">
import { usePocketCards, useRemovePocketCard } from "@use-truapi/vue";

const { data: cards } = usePocketCards();
const { remove, isPending } = useRemovePocketCard();
</script>

<template>
  <button
    v-for="card in cards?.filter((c) => !c.privileged)"
    :key="card.cardId"
    type="button"
    :disabled="isPending"
    @click="remove(card.cardId)"
  >
    Dismiss {{ card.cardId }}
  </button>
</template>
```
